**사용자가 *"내가 X라고 한 건 A 상황에서 말한 거고, B에서는 아니야"* 라고 말하면, 그것은 새 요구가 아니라 기존 요구의 적용 범위를 좁히는 정정이다. 태스크 행에 "이 신고는 범위 정정이다"를 별도 항목으로 적고, 좁혀진 쪽과 유지되는 쪽의 태스크 번호를 각각 명시한다.**

**Why:** 2026-07-27 신고 — *"통화가 유지되어야 한다"* 는 **통화↔문자 사이에만** 적용되며(T68·T103 계열), **통화→통화 전환은 호 전환이어야 한다**(T110). 이걸 명문화하지 않으면 다음 사람이 "통화 유지" 규칙을 통화→통화에도 적용해 원래 결함을 되살린다. 같은 신고가 **훈련 교훈 자체를 이동**시키기도 한다(AC-071: *"직접 건 확인 전화도 가로채진다"* → *"넘겨준 통화는 독립 확인이 아니다"*) — 그때는 planner가 판정하지 말고 [[ac-amendment-retroactivity]]의 선택지 3표로 넘긴다.

**How to apply:** 신고 원문에 *"~는 …에서 말한 거고"*, *"~는 아니야"*, *"~의 경우에는"* 이 있으면 범위 정정 신호다. 행에 ① 원 요구의 문면, ② 적용되는 범위, ③ **제외되는 범위와 그 쪽을 담당하는 태스크 번호**를 쓴다. 그리고 사용자 원문을 **인용부호로 그대로** 남긴다 — 요약하면 범위가 다시 흐려진다. 관련: [[followup-fixture-collision]], [[planner-edit-only-handoff]]
