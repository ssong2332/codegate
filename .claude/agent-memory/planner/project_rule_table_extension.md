**판정 규칙 표에 새 케이스를 넣으라는 지시를 받으면, 먼저 "섞을 것인가 분리할 것인가"를 판정하고 근거를 문서에 적는다. 그리고 넣는 행이 *기존의 강등 판정*을 뒤집지 않는지 대조해, 뒤집는다면 그 선례를 보존하는 방어 행을 함께 넣는다.**

**분리 판정 기준(2026-07-29 `docs/PRD.md` v1.13에서 실제로 쓴 것)** — 셋 중 하나라도 성립하면 **별도 표**:
1. **입력 축이 다르다** — 기존 행이 전부 받는 입력(예: 시나리오·제품 능력)과 새 케이스의 입력(예: 병합 후 잔여 검증)이 다르다.
2. ⭐ **표 주변 산문이 그 표의 적용 결과를 이미 닫아 서술한다** — 예: *"적용 결과: #28~#31 = P0(확장), #32 = P1(확장)"*. 행을 끼우면 **그 문장이 조용히 낡는데 append-only 규약상 고칠 수 없다.** 이것이 가장 강한 분리 근거다.
3. **산출 라벨의 축이 다르다** — 기존이 전부 `(확장)` 축인데 새 판정은 `(검증 신뢰성)`·`(프로덕션 견고성)`·`(검증 층 공백)` 축이다.

**⭐⭐ 방어 행(defensive row)을 빼먹지 마라.** 새 표가 "이 부류는 P1"만 규정하면, **같은 부류인데 이미 P2로 강등돼 있던 선례를 조용히 P1으로 올려 뒤집는다.** 2026-07-29 실측: 검증 갭을 P1으로 규정하는 표가 **T116(`P2(검증 층 공백)`)** 을 뒤집을 뻔했다 — T116의 강등 근거(*"오늘 오동작 0건" · "다른 층의 기존 검사가 같은 재발 경로를 이미 3겹으로 덮는다" · "비용이 가장 크다"*)를 **그대로 조건문으로 옮긴 행(V-4)** 을 넣어 보존했다. ⇒ **선례를 실측한 뒤, 각 선례가 새 표의 어느 행에 걸리는지 표로 대조해 보이고 "뒤집은 것 0건"을 근거와 함께 적는다.**

**"측정 불가" 케이스의 필수 조항** — *"측정 수단이 없어 판정 불가"* 행은 시간이 지나면 조용히 *"영향 없음"* 으로 바뀐다. 판정에 이것을 명문으로 금지하는 조항을 넣는다: (a) *"영향 없음·미미하다·리스크 낮음"* 재서술 금지, (b) ⭐ **무사고 기간은 강등 근거가 아니다**(측정 수단이 없다는 것이 전제이므로 문제가 나도 보이지 않는다 — 이 한 줄이 조항의 핵심이다), (c) 강등·종결은 **실측값 제출** 또는 **User의 명시적 확정**으로만, 후자도 *"미측정인 채로 수용한다"* 로 적는다, (d) 그 없이 `done`/`wontfix` 금지, (e) 이 항목의 미완을 이유로 병합된 원 기능을 되돌리지 않는다.

**행 개수 판정**: 지시가 준 "취지" 개수에 맞추지 말고, **취지가 서로 다른 라벨을 산출하면 분리, 같은 라벨이면 병합**한다. 여기에 **라우팅 행**(이 표의 대상이 아닌 케이스를 원래 표로 보냄)과 **방어 행**을 더하면 실제 행 수는 취지보다 많아진다 — 취지 3개 → 행 5개(V-0 라우팅 · V-1~V-3 취지 · V-4 방어)가 실제 결과였다.
