planner 에이전트에는 셸이 없을 때가 있다(도구 목록에 Bash 부재). `git log`를 요구받아도 실행할 수 없으므로 **파일 실측으로 대체하고, 대체했다는 사실을 문서와 보고 양쪽에 적는다.**

대체 경로(이 저장소에서 실제로 쓴 것):
- **base main 커밋** → main 체크아웃의 `.git/logs/refs/heads/main` **마지막 줄의 두 번째 해시**. (워크트리가 아니라 main 체크아웃 쪽 경로를 읽을 것)
- **직전 최대 T 번호** → `docs/Tasks.md`를 `^\| T1[01][0-9] \|` 로 grep. **워크트리와 main 체크아웃 양쪽**에서 확인(브랜치별로 다를 수 있다).
- **테스트 러너 제약** → 루트 `package.json`의 `scripts.test` 원문과 `devDependencies`. 나열된 테스트 파일 확장자(.ts만인지 .tsx가 있는지)가 러너 능력의 강한 단서다.
- **에뮬레이터가 무엇을 로드하는가** → `functions/package.json`의 `main`·`serve`·`test` 스크립트와 `firebase.json`의 emulators 블록.

**⭐⭐ 미병합 브랜치의 파일을 셸 없이 읽는 법(2026-07-28 T132 등재에서 실제로 썼다)**: 지시문이 `git show origin/<branch>:docs/X.md` 로 읽으라고 해도 Bash가 없으면 실행할 수 없다. ⇒ **그 브랜치가 체크아웃된 다른 에이전트의 워크트리를 찾아 직접 Read한다.** 절차: (1) 그 문서에만 있을 고유 문자열(예: `^## 37\.`)을 `C:\codegate\.claude\worktrees` 전체에 Grep해 히트 워크트리를 찾고, (2) **브랜치 동일성을 반드시 확인**한다 — 워크트리의 `.git` 파일(`gitdir: C:/codegate/.git/worktrees/<id>`)을 Read하고 그 경로의 `HEAD`를 Read해 `ref: refs/heads/<branch>` 가 지시문의 브랜치명과 일치하는지 본다. ⛔ 확인 없이 읽으면 **다른 브랜치의 다른 버전을 정본으로 오인**한다. ⚠️ `C:\codegate\.git` 하위를 Glob하면 **20초 타임아웃**이 난다 — Glob 대신 정확한 경로 Read나 Grep을 쓸 것. ⭐ 또한 그 문서가 적은 base 해시와 현재 main 해시가 다르면 **병합 시 파일:줄 인용이 밀렸을 수 있다**를 태스크 행에 명시한다.

**Why:** 셸 없이 "추정"으로 적으면 CLAUDE.md 금지사항(추측을 사실처럼)에 걸리고, 반대로 "확인 불가"로 비워 두면 착수자가 낡은 값을 그대로 쓴다. 파일 실측은 근거를 남기면서 둘 다 피한다.

**⭐ 병합 판정(2026-07-28 상태 정리 패스에서 확립)**: `.git/logs/refs/heads/main`은 **fast-forward 구간의 중간 커밋을 남기지 않는다** — 로그 각 줄은 `이전해시 → 새해시`뿐이라 PR 병합 커밋이 그 사이에 있으면 **로그에 나타나지 않는다.** ⛔ **해시가 로그에 없다는 것은 미병합의 증거가 아니다.** ⇒ 병합 판정은 **① 산출물 파일 실재(주 근거) + ② 로그에 해시가 실제로 보이면 보강**의 2단으로 하고, 보이지 않는 해시는 *"오케스트레이터 실측 인용값 — planner 미대조"* 로 명시한다. 같은 패스에서 8건을 이 방식으로 `merged` 정정했다.

**⭐ `merged`로 적으면 안 되는 경우**: 소스·문면은 병합됐지만 **라이브/실행 검증이 남은 태스크**는 `merged`가 아니라 `review(라이브 검증 대기)`로 적는다 — `merged`는 다음 사람에게 *"이 건은 끝났다"* 로 읽혀 남은 검증이 조용히 사라진다(T125 사례: 문면 교체는 병합, 9건 세트 라이브는 미실행, architect가 *"충돌이 절반만 풀렸다"* 를 자기 고지해 둔 상태였다).

**⭐⭐ 셸 없이 *커밋 메시지 본문*을 읽는 법(2026-07-29 발견)**: `C:\codegate\.git\COMMIT_EDITMSG`는 **그 체크아웃에서 마지막으로 작성된 커밋 메시지 전문**이라 **평문 Read가 된다.** 커밋 객체는 zlib이라 못 읽지만 이 파일은 읽힌다 ⇒ **`Refs:` 트레일러·본문 주장·인용 수치를 "인용값"이 아니라 실측으로 승격**할 수 있다. ⛔ 한계: **마지막 1건뿐**이고 **그 체크아웃에서 만든 커밋만** 남는다(웹 병합 커밋·다른 워크트리 커밋은 없다). 이 날 이것으로 `Refs: T146`(`:21`)을 직접 확인해 번호 사고를 확정했다 — [[ac-number-reservation]].

**⭐⭐ `git log --grep=...` 의 대체(2026-07-29 확립)**: 지시문이 *"`git log --grep="미등재"` 로 찾아 전수 등재하라"* 처럼 로그 검색을 요구하면 **`C:\codegate\.git\worktrees` 전체를 Grep**한다 — 각 워크트리의 `COMMIT_EDITMSG`가 평문이라 **그 에이전트가 마지막으로 만든 커밋 메시지 전문**이 걸린다. 이 날 이 방법으로 **`Refs: (미등재 — planner 인계)` 커밋 6건을 원문째 회수**해 전수 등재했다(§43·§44·§45·UX v1.19·UX 여백 설계·측정 하네스). ⛔ **한계 2가지**: **워크트리당 마지막 1건뿐**이고 **웹 병합 커밋은 안 남는다** ⇒ 회수분이 전수라는 보장이 없으니 **"이 방법으로 찾은 N건"** 으로 정직하게 적고, 병합 판정은 **산출물 실재 grep**으로 따로 세울 것. ⭐ 같은 디렉터리를 `Refs: T1[0-9][0-9]` 로 grep하면 **트레일러가 소진한 T번호**도 함께 회수된다.

**⭐⭐ 2026-09-07 — `COMMIT_EDITMSG` 경로가 통째로 사라질 수 있다. 대체는 *공개 원격의 커밋 API*다.** 이 날 `C:\codegate\.git\worktrees` 에 등록 워크트리가 **0건**이었고(`Glob */COMMIT_EDITMSG` = 결과 없음) `.git/COMMIT_EDITMSG`도 이 체크아웃의 마지막 1건뿐이라 **위 26행의 워크트리 grep 기법이 성립하지 않았다.** ⇒ **`https://api.github.com/repos/<owner>/<repo>/commits?sha=main&per_page=40` 을 WebFetch** 하면 병합 커밋 메시지·`Refs:` 트레일러를 **웹 병합분까지** 읽을 수 있다(이 저장소는 public: `ssong2332/codegate`). ⛔ **함정**: WebFetch는 **요약 모델을 거쳐서 "전문을 그대로 인용하라"고 해도 요약해 버린다** — 이 날 첫 시도가 그렇게 실패했다. **해법은 질문을 한 줄짜리로 좁히는 것**: *"`Refs:` 로 시작하는 줄만 SHA와 함께 그대로 인용하고 없으면 NO REFS LINE"* 으로 물으면 원문이 나온다. ⇒ **트레일러 문면은 이 경로로, 산출물 실재는 로컬 grep으로 — 2단 확인**. 이 날 이것으로 미등재 커밋 9건을 특정해 T161~T168로 등재했다.

**⚠️ Glob의 하위 디렉터리 패턴이 조용히 0건을 낸다(2026-09-07 실측)**: `.git/refs/heads` 에서 `*/T1*` · `*/T1[5-9]*` 는 **"No files found"** 였지만 **같은 자리에서 `*` 는 `fix\T52-…` 를 정상 반환**했고, `path` 를 `.git/refs/heads/docs` 로 내려 `T1*` 로 물으면 **53건**이 나왔다(최대 `T157`). ⛔ **0건을 "브랜치가 없다"로 읽으면 번호 실측이 통째로 틀린다** — **접두 디렉터리마다 따로 Glob**할 것(`docs`·`feat`·`fix`·`chore`·`test`). 같은 날 `packed-refs`는 **아예 없었다**(Grep이 `across 0 files`) — 그 부재를 "브랜치 없음"의 근거로 쓰지 말 것.

**⚠️ Glob 타임아웃 지도(2026-07-29 실측)**: `C:\codegate\.git\**` 전체 · `functions/src/**/*.ts` 같은 넓은 소스 Glob · `.claude\worktrees\rev*` → **20초 타임아웃**. `refs/heads/*` → 되지만 **142개 중 100개에서 잘린다**. ⇒ **Glob 대신 Grep(내용 기반)으로 파일 실재를 확인**하는 편이 빠르고 안전하다(예: 테스트 파일 실재는 그 파일에만 있는 심볼을 디렉터리 한정 Grep). 타임아웃으로 대조 실패한 항목은 **"인용값 — planner 미대조"** 로 명시할 것.

**How to apply:** 실측한 값에는 **읽은 파일 경로와 줄**을, 실측하지 못한 값에는 **"추정" 표시 + 확인 절차**를 붙인다. 커밋 해시·테스트 수 같은 값은 어차피 곧 낡으므로 문서에는 항상 **"착수 시 재측정"** 을 함께 못박는다. 관련: [[project_baseline_correction]], [[project_ac_verifiability]]
