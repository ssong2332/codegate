한국어 어형을 정규식으로 넓힐 때의 판단·함정 4건(T112, 2026-07-28, PR #138).

**1. "대안 추가" 대신 형태 슬롯 — 슬롯은 4개면 충분했다.**
활용형을 통째로 적은 대안(*"하신 적 있"*)은 어미 한 칸에 새 나간다. 어간 활용부 + 뒤따르는 문법 요소로 쪼개니 표본 8개가 **슬롯 4개**로 덮였다(경험·이력 / 간접 의문 `-는지` / 존대 과거 의문 종결 `셨+어미` / `여부`+요구동사). 소재 명사 0개.
**Why:** 이 저장소는 T110에서 정규식 의미 판정으로 4라운드를 태웠고, 어휘 열거는 T86에서 데였다.
**How to apply:** 한국어 검출 축을 넓히라는 지시가 오면 먼저 "표본들이 공유하는 **문법 슬롯**이 뭔가"를 표로 적고 그 표로만 정규식을 만든다. 슬롯이 6개를 넘어가면 방식이 틀린 신호.

**2. ⭐ `-는지`는 의문 어미이면서 **내포절** 어미다 — 여기서 유일한 오탐이 났다.**
*"잔액 얼마 **있으신지 확인해서** 전액 이체해 주십시오"* 가 `이체`와 겹쳐 요구 2건으로 오판(조립 24벌 + T113 역검증 동반 실패). 가르는 실제 축은 **누가 확인하는가**: *"확인해**서**"*(화자) vs *"확인해 **주**"*(참가자). 후행 요소를 lookahead로 요구해 닫았다. 같은 이유로 `여부` 슬롯의 맨 `확인`도 규칙 산문 *"명의 도용 여부 확인"* 에 걸렸다.
**How to apply:** 한국어 종결/연결 어미를 검출축으로 쓸 때 **그 어미가 내포절도 만드는지** 먼저 의심하라. `-는지`·`-ㄴ지`·`-지`가 대표. lookahead로 후행 요소를 요구하면 매치 문자열이 짧게 유지돼 `countsPerMatch: true` 계수도 안 흔든다.

**3. A/B 프로브는 증거만 뽑고 지웠다 — 영구 단언으로 만들면 가짜 게이트가 된다.**
old/new 패턴을 콘텐츠 전수에 돌려 `신규검출 0건`을 뽑는 임시 test를 넣고, 출력 확보 후 삭제했다. 영구화하면 **콘텐츠가 정당한 사실 조회를 새로 넣는 순간** 깨진다.
**How to apply:** "오탐 0건 전수" 요구는 *측정*이지 *단언*이 아니다. 임시 `t.diagnostic` 테스트로 뽑고 지운 뒤 보고서에 수치를 남긴다. 반대로 **표본 검출**은 영구 테스트로 남긴다(죽은 패턴 방지).

**4. 새 워크트리 `npm install`이 package.json을 몰래 고친다 — 루트·functions **양쪽** 다.**
`functions/package.json`에 `"fraud-vaccine-web": "file:.."`, 루트 `package.json`에 `"fraud-vaccine-web": "file:"` 이 추가됐다. 커밋 전 `git status`로 잡아 `git checkout --` 했다.
**How to apply:** 워크트리에서 install 직후 반드시 `git status --short` → manifest 2쌍(package.json/lock) 되돌리기. [[codegate-t107-field-divergence]]에 functions 쪽만 적혀 있었는데 루트도 같다.
