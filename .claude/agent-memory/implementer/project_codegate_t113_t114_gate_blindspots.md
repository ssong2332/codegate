T113(조립 축 미순회) + T114(§22.1 ↔ 화이트리스트 미연결)을 한 브랜치로.
`feat/T113-T114-gate-blindspots`, 커밋 `8ebe67d`, PR #136. base main `ff54be9`.
둘 다 ***"게이트가 자기 근거의 변경을 못 본다"*** 부류(T106·T113·T114가 이 저장소의 3연속 사례다).

**1. ⭐⭐ 역검증에서 **거짓 음성을 실제로 밟았다** — 정본이 복제돼 있으면 조작도 전수여야 한다.**
§22.1 문면을 지운 사본으로 게이트가 실패하는지 보는 테스트에서 `String.replace`를 썼는데
`RECONNECT_TAIL`은 **카탈로그 6종에 각각 복제**돼 있어 첫 한 벌만 지워졌고, 나머지 5벌 때문에
`includes()`가 계속 true → **게이트가 초록불**(`not ok 495`로 드러남).
**Why:** 역검증이 "조작했는데 안 잡힌다"를 보여 주려는 도구인데, **조작 자체가 실패**하면
연결이 멀쩡한 코드도 결함으로 보이고(이번엔 반대로 내가 만든 게이트를 의심했다), 반대 방향으로는
**조작이 부분만 먹혀 거짓 초록**이 난다.
**How to apply:** 변조 사본을 만들 때 ① 대상 문자열이 정본에 **몇 번** 나오는지 먼저 세라,
② 1회 치환 대신 전수 치환(`split(x).join(y)`)을 기본으로 써라, ③ 그 이유를 테스트 주석에 남겨라.
관련: [[false-reassurance-over-precision]] · [[codegate-t125-verify-scope]](부분 음성 선례)

**2. ⚠️ `functions/`의 tsconfig target에서 `String.replaceAll`이 없다**(TS2550, es2021 미만).
`split(x).join(y)`로 대체한다. **tsconfig를 고치지 마라** — 범위 밖이고 컴파일 대상 전체에 영향이 간다.

**3. ⭐ 화이트리스트를 문서에 이을 때 — "문서가 문면을 **적었는가** 지목만 했는가"를 갈라라.**
퇴장 술어 6종 중 5건은 §22.1이 문면을 그대로 적어 뒀지만, 1건(`같은 사람이라는 사실…말하지 마라`)은
§22.1 A3가 *"기존 `RECONNECT_TAIL` 유지"* 라고 **지목만** 한다. 이걸 문서에서 찾게 짜면
**영구 거짓 빨간불**이다 — 대조 대상을 그 상수(카탈로그 산출물)로 갈라야 한다.
**How to apply:** 링크 항목마다 `origin` 필드를 두고 대조 대상을 분기시켜라. 그리고
**리터럴은 마크다운 강조(`**`)를 포함하지 않는 최단 구간**으로 잡아라 — 강조 표기만 바뀌어도
빨간불이 나면 다음 사람이 게이트를 끈다(이 저장소는 고마찰로 게이트를 잃은 전례가 있다).

**4. ⭐ 축을 늘릴 때 "곱할지 더할지"는 **게이트의 판정 폭**으로 정한다(조합 폭발 방지).**
판정이 **인용구 1개 단위 / 매치 ±N자**면, 블록을 연결만 하는 옵션은 **곱해도 검출력이 안 는다.**
  | 형태 | 처리 |
  |---|---|
  | 다른 블록과 **함께** 있을 때만 보이는 것이 있다(윈도가 경계를 넘는다) | **곱한다** |
  | 특정 값에서만 읽히는 옵션(고급에서만 읽는 `l3Procedural`) | **그 값에만 곱한다**(아니면 동일 문자열 복제) |
  | 상수가 아니라 **호출부가 넘기는 값의 집합** | **곱하지 않고 더한다**(여기선 22종 — 곱하면 6,160벌) |
실측: 112 → 302벌, 게이트 1이 36.0ms → 231.3ms. **스위트 전체 시간은 회차 편차(11.7~21.4초)가
차이보다 커서 판정 불가**였다 — 이럴 땐 **per-test `duration_ms`를 근거로 쓰고 그렇게 밝혀라.**

**5. 재발 방지는 "옵션 키 ↔ 스캔 헬퍼" 소스 대조로 고정했다.**
`export type BuildSystemPromptOptions = {...}`를 파싱해 키를 뽑고, 그 키가 스캔 헬퍼 구간 소스에
전부 나오는지 본다. **주석은 반드시 걷어내고 봐라** — 내 설명 주석이 모든 옵션 이름을 언급하고 있어
그대로 두면 **거짓 초록**이다(이 저장소의 반복 함정이 이번엔 반대 방향으로 나왔다).
검증법: 축을 하나씩 지운 **사본**으로 5/5 전부 적발되는지 probe로 확인.

**6. planner가 인용한 문면·줄번호는 같은 날에도 낡는다.**
T113 A/B항이 인용한 `"잠시만요, 담당 창구를 확인해 알려드리겠습니다"` 는 T125 1·2차가 바꿔서
**현재 파일에 없다**. 인용을 믿지 말고 파일을 읽고, 실측값으로 갈아 보고하라.

**7. 모듈 지역 상수는 게이트가 못 본다** — `OPENING_TURN_INSTRUCTION`을 export로 바꿔야
스캔 대상에 들어왔다. 1단어 변경이고 이유를 그 자리 주석에 남겼다.
