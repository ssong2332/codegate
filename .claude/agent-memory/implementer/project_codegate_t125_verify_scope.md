## 1. ⭐ 이 저장소에서 처음으로 **라이브가 부분 음성으로 끝난** 태스크다

소스 게이트·역검증·무회귀가 **전부 초록불인데 증상은 3회 중 2회 재현**됐다(base 대조군 1/1 재현).
`docs/Architecture.md` §28.8 1이 *"프롬프트 층 수단이라 보장이 아니다"* 를 미리 적어 뒀고 **그대로 실현**됐다.

**Why:** 이 저장소의 라이브 검증은 그동안 *"미재현"* 으로 끝나 왔다. T125는 **미재현조차 주장할 수
없는 결과**여서, *"테스트가 늘었으니 고쳐졌다"* 로 읽히지 않게 쓰는 형식이 처음 필요했다.

**How to apply:** 프롬프트 층(시스템 프롬프트 문면)으로 모델 행동을 바꾸는 태스크는
**착수 시점에 "부분 음성이 정상 결과일 수 있다"를 계획에 넣어라.** 보고에서는 회차별 표
(회차 / 판정 / 발화 원문)로 내고, **합격 회차만 인용하지 마라.** PR·Tasks.md Status·커밋 메시지
**세 곳 모두**에 잔여 증상을 적어야 다음 사람이 닫힌 문제로 오인하지 않는다
([[codegate-t118-transfer-persistence]]의 *"라이브에서 본 것을 산출물에 안 옮기면 없는 것이 된다"* 의 재확인).

## 2. ⭐ "모순 제거"와 "조건 분리"는 **다른 설계 후보 집합**을 만든다

사용자 판단(*"전화를 끊으려고 하면 막아야 하는 거 아니야?"*)이 프레이밍을 **조건 분리**로 확정하자
*"충돌하는 수법 문면을 좁힌다"* 후보가 통째로 기각됐다 — **수법 약화 = 사용자 의사 위반**이 되기 때문.

판정을 가른 실측 한 줄: **선언을 어디에 얹느냐가 아니라, 그 자리가 어떤 조건에서 방출되느냐.**
`VERIFY_INTERCEPT_RULE`은 `verifyInterceptEnabled`(카탈로그 && 고급)에서만 붙고 **그게 곧 문제
조건과 일치**한다. `weakenedTactics`·`personaPrompt`는 **무조건 방출**이라 조건을 모른다.

**How to apply:** "규칙 A와 규칙 B가 충돌한다"는 태스크에서 **먼저 각 문자열의 방출 조건을 grep으로
확인하라.** 방출 조건이 문제 조건과 일치하는 자리가 있으면 그곳이 유일하게 옳은 편집 지점이고,
무조건 방출되는 자리를 고치면 **문제와 무관한 세션까지 함께 바뀐다.**

## 3. 라이브 대조군이 **실제로 갈랐다** — ⓵을 생략했으면 오보였다

base main(선언 없음)에서 같은 대본으로 1회 돌려 **저지가 재현되는 것을 먼저 확인**했다.
만약 PR-1(의도대로 동작)만 보고 끝냈으면 *"고쳤다"* 로 오보했을 것이고, base가 미재현이었다면
PR 회차의 성공도 공로가 아니었다. **두 방향 모두 대조군 없이는 판정 불가다.**

**반대 방향(⓸) 1회가 반려 방지선이다**: 확인 언급 없이 *"바빠서 끊을게요"* 에 저지가 유지되는지.
여기서 저지가 사라지면 예외 선언이 **과일반화**된 것이고 사용자 요구를 깬 것이다.
⇒ 라이브 예산이 모자라면 **⓸을 PR 추가 회차보다 먼저 확보**하라.

## 4. 함정 — `createRealtimeCall` 응답 필드명

Mock 판정은 `isMock`이고 토큰·모델 필드는 **`geminiToken` / `geminiModel`**(`realtime/callTypes.ts`)이다.
`token`/`model`로 쓰면 조용히 undefined가 되어 하네스가 엉뚱한 곳에서 죽는다.
⚠️ **`createSession`의 `isMock`은 다른 것**(오프닝 대사 LLM)이라 true여도 실시간 경로 증거는 유효하다 —
회차마다 값이 갈렸다. **판정에 쓸 `isMock`은 `createRealtimeCall` 쪽이다.**

## 5. 새 워크트리 착수 비용 — 이번엔 매니페스트 드리프트가 **없었다**

`node_modules` 부재는 그대로 재발(루트·functions 둘 다, 설치 전 테스트는 TS2307 수백 줄로 죽는다).
다만 [[codegate-t119-offer-gate-values]]가 기록한 *"install이 `functions/package.json`을 고친다"* 는
**이번엔 발생하지 않았다**(설치 후 `git status` 깨끗). ⇒ 항상 일어나는 일이 아니니
**되돌리기 전에 `git status`로 실제 드리프트를 확인**하고, 없으면 손대지 마라.

격리 에뮬레이터 포트는 `netstat`로 훑어 5725/8725/9725/9726/4725를 골랐다(9099·9199·9499 대역은
다른 에이전트가 점유 중). 종료는 포트 PID → `taskkill //PID <pid> //F`.
**끝나면 `functions/.env` 키 사본과 임시 config를 반드시 지울 것**(둘 다 지웠고 `git status`로 확인).
