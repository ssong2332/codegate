"X 하기 전에 먼저 도구" 류 문면이 지켜지지 않았다는 신고(T192 C6-F2, P-H H1 위반 1/19)는 모델 탓 전에 **문면의 범위**를 판독한다.

- 비교 대상: "작별 인사를 하기 전에 먼저"는 종료 *선언*("이제 통화 끝내겠습니다")을 비교 대상에서 뺀다.
- 면제 조건: "도구를 부르지 않은 응답에서는 … 말하지 않는다"는 도구를 부른 응답을 면제한다 → 같은 응답 안 도구 앞 선언이 합법.
- 처방은 비교 대상을 "그 응답의 어떤 말보다도"로 넓히고, 관측된 진입로(결과 알림·선언)를 범주어로 순서 금지. 다른 규칙의 예시 리터럴은 인용하지 않는다(말하라/말하지 말라 모순).
- 유도 규칙(타 소유)과 닫는 자리(내 소유)를 갈라 적는다.

**Why:** 원인 후보 둘(C6-F 문장 vs A-1 NO_STALL)을 저울질하는 동안, 실제로 위반을 *허용*한 것은 우리 문면의 범위 구멍이었다.

**How to apply:** 위반 기저율이 낮으면(≈5%) 재측정 0/n은 효과 0이어도 자주 나온다(0.947^19≈36%) — 기저율이 더 높은 선행 지표(호출 전 발화 비율 3/19)를 관측 열로 함께 둔다. 관련: [[prompt-layer-two-strikes]] · [[model-utterance-grep-the-prompt]]
