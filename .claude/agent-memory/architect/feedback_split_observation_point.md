**판정 대상 관측 지점이 늘어나면, 분류 **범주**를 신설하지 말고 **기존 범주를 새 지점에 그대로 적용**한다. 그리고 새 지점을 성패 판정의 분자·분모에 넣을지는 **부호(방향)** 를 먼저 확인한다.**

**Why:** T125 라이브에서 *"첫 요구 응답"* 이라는 새 관측 지점이 정보값을 냈다. 범주를 늘렸다면 **이전 관측 전부가 재분류 대상**이 됐을 것이다. 더 위험했던 것은 부호다 — 새 지점의 *"이양"* 은 채택된 설계와 **반대 방향**이라(설계는 그 지점에서 *만류*를 원한다) 기존 분모에 합산하면 **성공/실패 부호가 뒤집혀** *"교체가 불필요하다"* 는 정반대 결론이 나올 수 있었다.

**How to apply:**
- 지점 추가 시: 기존 범주표 무변경 + 회차 기록에 `P1 범주 / P2 범주`처럼 **지점을 명시**해 적는다 ⇒ 재분류 0건.
- 새 지점을 성패 임계(≥4/5 등)에 넣기 전에 **"이 지점에서 좋은 값은 무엇인가"** 를 먼저 적어라. 방향이 반대면 **기록·전제 검사 입력으로만** 쓰고 분모에서 뺀다.
- 기존 판정표의 범주 기호가 **어느 지점 기준인지** 명시적으로 못 박아라 — 안 하면 다음 사람이 다른 지점 값을 같은 행에 대입한다.
