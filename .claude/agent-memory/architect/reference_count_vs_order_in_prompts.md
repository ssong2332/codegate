LLM 프롬프트에서 *"한 번만 X하고 두 번째엔 Y"* 같은 **횟수·서수·턴 인덱스** 조건은 이 아키텍처에서 성립하지 않는다. **순서·조건**으로 다시 쓰면 성립한다.

**판정 기준은 "조건의 참조 대상이 어디 있는가" 하나다:**
- ❌ 참조 대상이 **프롬프트 밖**(별도 주입 턴, 외부 턴 카운터) → 실시간 경로는 systemInstruction이 setup 1회 고정이라 **어느 턴에도 참이 되지 않는다**(§25.2 ㉡ 실측).
- ✅ 참조 대상이 **대화 기록 안**(상대가 같은 요구를 다시 말했다) → 폴백은 이력 전량 재조립, 실시간은 세션 컨텍스트 누적 ⇒ **모델이 세지 않고 관찰한다.**

**How to apply:**
- 문면 요건에 *"숫자·서수 금지, `먼저 … 그러고도 다시 …하면` 형태 필수"* 를 넣는다. 횟수 조건은 **어겨도 소리가 나지 않아** 게이트로 잡히지 않는다.
- "서버가 대신 세면 되지 않나"를 먼저 확인하되, **세는 대상이 무엇인지 코드로 볼 것** — 이 저장소의 오퍼 게이트는 **턴 경계(내용 무관)** 를 셀 뿐이고, 참가자 의사를 세려면 발화 분류가 필요해 AC-024 위반이 된다.
- 그래도 **보장이 아니다**: 참조 대상 존재는 *"판정이 원리적으로 가능"* 까지이고 *"모델이 그렇게 판정한다"* 가 아니다.
