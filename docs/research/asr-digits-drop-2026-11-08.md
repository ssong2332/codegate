### 대가(G311)
| 변경 | 대가 |
|---|---|
| 침묵 400 → 1000ms | 모든 응답이 약 0.6초 늦어진다(2026-07-24 "지연이 길다" 신고로 낮춘 값 · Google 문서 권장 하한 500ms · 서버 기본 약 800ms) |
| 시작 문턱 300 → 150ms | 짧은 잡음이 발화 시작으로 잡힐 여지 소폭 증가. 사기범 발화 중에는 반이중 게이트가 마이크를 막으므로 자기 끊김(§50.8)의 주 경로는 그대로 막혀 있다 |

## 4. 실 키 확인 실측(승인 대기)
`scripts/live-mic-probe.mjs` 3세션 — 같은 Heami 클립 6개 · ① 운영값(400/300) ② 침묵 1000 ③ 침묵 1000 + 시작 150. 보는 것: 발화마다 입력 전사 전문 · 게이트에 버린 프레임 · 인증번호 판정. 스크립트는 운영 토큰 설정(이제 1000/150)을 그대로 쓰므로 ① = `--silence-ms 400 --prefix-ms 300` · ② = `--prefix-ms 300` · ③ = 덮기 없음. `--prefix-ms`는 이 PR이 더한 측정 전용 옵션(`--silence-ms`와 같은 방식)이다.
⚠️ 다른 측정 스크립트(`duration-probe` · `full-audit-probe` · `live-turn-probe` · `stall-probe` · `live-asr-language-probe`)는 400/300을 직접 적어 둔 사본이라 이 PR에서 바꾸지 않았다(후속 판단).
