### C01 의사 41억 (검사→가짜 금감원 릴레이 + 가로채기) | 2022 보도 | S15
- 흐름: 서울중앙지검 검사 사칭 전화 → 카톡 친구 추가 시키자 프로필에 검찰 로고 → 고소장·공무원증, 이어 구속영장 청구서·공문 전송 → "협조하면 약식조사로 끝난다"(안심)와 "안 하면 구속수사"(협박) 병행 → 협조 약속 직후 "보안프로그램" 링크 → 악성앱(강제 수신·발신) → 예금·주식·아파트담보대출로 현금 마련해 전달.
- 채널 순서: 전화 → 카카오톡(친구추가) → 문서 이미지 → 링크(앱) → 확인전화 가로채기.
- 사기범: 최소 2명(검사 사칭 유인책, 금감원 직원 사칭). 교대 있음.
- 의심 시 대응: 유인책이 먼저 "직접 확인해 보라"고 권함 → 피해자가 금감원 홈페이지 번호로 걸자 다른 조직원이 받아 금감원 직원 행세. 확인 행위 자체를 각본에 넣음.
- 피해: 약 한 달, 41억 원.

### C02 택시기사 (대출 갈아타기 + 가짜 금감원 대면) | 2022 보도 | S15
- 금융사 콜센터 사칭 "저금리로 갈아탈 수 있다" → 안내받은 '금감원 콜센터'도 가짜, 기존 대출을 현금 상환하면 금감원 직원이 처리한다고 답 → 금감원 직원이라는 남성이 대면 등장.
- 의심 시: 피해자가 파출소로 동행. 수거책이 "채권추심 직원"이라 둘러대 경찰이 개입 안 함 → 파출소 앞에서 2,500만 원 전달. 사흘 뒤 1,500만 원 추가 피해.

### C03 카드배송 사칭 70대 21억 | 2025-02 경보 | S4
- 흐름: 배송원(전화 또는 위조 실물카드 들고 방문) → 미신청 카드 발급 믿게 함 → 가짜 카드사 고객센터 번호로 피해자가 직접 전화 → '명의도용 사고' 보안점검 명목 원격제어앱 설치 → 1332·1301로 걸어도 사기범 연결 → 검찰 사칭(구속 협박) + 금감원 사칭(약식수사 도와줌) → 자산보호·공탁금 명목 이체.
- 사기범: 배송원/상담원/검사/금감원 최소 4역할. 가족에게 말하면 가족도 수사대상이라 위협.
- 의심 시: 은행 이상거래 탐지로 본인 확인이 왔으나 피해자가 "아들 사업투자"라고 둘러대 거절(사기범의 사전 코칭 추정).
- 피해: 21억 원.

### C04 카드배송 → 112도 가로채기 (구조 성공) | 2025-02 발생 / 04-02 발표 | S22
- 미신청 카드 배송 연락 → "휴대폰에 문제" → 원격제어앱 설치 → 그 앱으로 악성앱 설치 → 112·1301·1332 모두 사기범 수신.
- 의심의 방향이 뒤집힘: 피해자는 찾아온 실제 경찰과 통신사 직원을 사기범으로 의심. 경찰서로 데려가 설명 후 앱 삭제. 큰 금액 송금 직전.

### C05 대전 모텔 셀프감금 20대 (구조) | 2025-05 | S25
- 전날부터 검사 사칭 연락 → 가짜 수사서류 → "계좌가 범죄에 쓰였다" 장시간 추궁 → "혼자 있을 곳에서 대기, 안 따르면 구속" → 모텔 20여 시간 통화 유지 → 공기계 구입, 원격제어앱 설치(악성앱 3개 발견).
- 남자친구 신고 내용상 금감원·경찰·수사관 사칭자와도 통화 → 여러 역할 등장(인원 미상).
- 의심 시: 피해자가 경찰을 의심하고 휴대폰 확인을 막음. "금감원에 가면 직원이 만나준다"는 사기범 말을 근거로 듦. 경찰이 대검 찐센터 확인 등 40분 설득.

### C06 안전폰 셀프감금 20대 1,700만 원 | 2025-09 보도 | S28

- 사기범 2명, 교대(검사 → 금감원). 안전폰엔 발신번호를 기관 번호로 보이게 하는 악성 소프트웨어.
- 의심 시: 피해자가 신분증·이름·번호를 인터넷으로 검색 → 실재 정보라 오히려 확신. 토스뱅크 직원 전화도 무시하고 이체, 이후 직원 5시간 설득으로 인지.

## 관찰 A: 문자·메신저 발송 순서 (확인된 사례 기준)
| 사례 | 첫 접촉 | 두 번째 | 이후 |
|---|---|---|---|
| C01 41억 | 전화 | 카톡 친구추가 지시 → 문서 이미지 | 협조 약속 후 앱 링크 → 확인전화 가로채기 |
| C03/C04 카드배송 | 전화(또는 방문/문자) | 피해자가 가짜 고객센터로 전화 | 원격앱 → 악성앱 → 기관 전화 가로채기 |
| C05 대전 | 전화 | 가짜 수사서류 | 장소 이동 → 공기계 → 원격앱 |
| C06 안전폰 | 전화 | 실물 '안전폰' 수령 | 그 폰으로 다른 역할 전화 |
| C08 표준형 | 배송 빙자 연락 | 사이트 개인정보 입력 → 가짜 영장 | 시그널/텔레그램 이동 → 구형폰 → 숙박업소 |
| C13 대출 | 광고(검색)·연락처 남김 | 텔레그램/전화 상담 | 서류 → 선입금 / 앱 |
| C15 메신저 | 문자 | 대화 성립 후 링크·앱 | 신분증 사진 → 계좌·카드 사본 |
| C16 납치 | 전화 | 울음소리 | 즉시 이체 요구 |
| C20 노쇼 | 전화 | 명함·공문 전송 | 소액 거래로 신뢰 → 대리구매 |

정리:
1. 문서·링크는 대개 첫 접촉이 아니라 "말로 겁을 준 뒤" 또는 "피해자가 협조를 약속한 뒤"에 온다(C01, C05, C15).
2. 대출·사칭 사례에서 문자는 사기범이 아니라 실제 금융사·통신사가 보내는 경우가 있다고 추정됨 — 명의도용 개통·비대면 계좌·대출 실행 시 정상 인증 문자가 피해자 폰으로 오며, 악성앱이 이를 가로채거나 삭제(S31: 문자 수신·삭제 기능). 이 경우 문자 시점은 사기범 행동에 따라 달라진다(추정, 기사에 '인증문자 가로채기' 문구 직접 없음).
3. 항상 '인증번호 → 이체' 같은 고정 순서는 사례에서 확인되지 않음. 오히려 확인된 순서는 사례마다 다르며, 앱 설치가 있으면 그 이후엔 문자가 피해자에게 보이지 않을 수 있음.

## 관찰 B: 대화 주도권
- 사기범은 피해자의 확인 행동을 미리 각본에 넣는다: "직접 확인해 보라"(C01), "금감원 가면 직원이 만나준다"(C05). 피해자가 검색해도 실재 이름·번호가 나오게 설계(C06, C12).
- 통화를 끊지 못하게 한다(S17 십계명 1번, S26), 장시간 독점(C05 20시간, C07, C12 11시간).
- 질문 방식: 사기범은 계좌번호·비밀번호를 직접 묻지 않고 거래 은행·자산 규모 같은 정보를 물어 대상을 고른다(S12 금감원·국과수 분석).
- 의심이 생기면: 제3자(은행·경찰)를 오히려 의심하게 만든다(C03, C04, C05, C07), 은행 확인 전화에 둘러댈 답을 준다(C03 "아들 사업투자"는 코칭으로 추정).
- 피해자 말을 듣는 정도: 기사 기준으로 정량 근거 없음(미확인). 정성적으로는 "협박 ↔ 안심"을 번갈아(C01 구속수사 vs 약식조사) 피해자 반응에 맞춰 조절하는 모습.
