# 화면 꺼짐 · 백그라운드에서 훈련 통화가 멈추는 문제 — 조사 · 대응 · 실기 체크리스트 (2026-10-21)

> 신고(2026-10-21, 갤럭시 S25 · 웨일 · 크롬): *"핸드폰이 꺼지면 마이크를 통해서 웹사이트에 전달하지 못하는 거 같은데, 해당 부분 해결방안 강구하자"*
> 구현: `docs/Architecture.md` §99 · UX D-142 · DECISIONS #212.

## 금지 · 전제
- ⛔ 아래 "브라우저 동작" 표의 **추정** 행은 실기 확인 전 사실로 쓰지 않는다. 확인 방법은 §4 체크리스트.
- 웹 페이지는 OS 근접 센서 · 전원 버튼 · 앱 전환을 막을 수 없다. 웹이 할 수 있는 것은 ① 자동 꺼짐 방지 ② 돌아왔을 때 복구 ③ 안내뿐이다.

## 1. 현상 분해 — 무엇이 멈추는가

| 상황 | 마이크 트랙 | AudioContext | Live 소켓(WebSocket) | 재생 | 근거 · 확신도 |
|---|---|---|---|---|---|
| 화면 자동 꺼짐(시간 초과 — 갤럭시 기본 30초) · 안드로이드 크롬 계열 | **추정**: 앱이 유휴로 분류되면 OS가 0으로 채운 버퍼를 준다(트랙은 `live`·`muted:false`로 보일 수 있다) | 추정: running 유지 또는 suspended | 추정: 한동안 유지, 오래 꺼지면 끊김 | 추정: 계속 | Android 9 유휴 앱 마이크 제한 [XDA][hn] · 크롬 백그라운드 탭 제한 [chrome57] — **실기 미확인** |
| 전원 버튼으로 끔 · 안드로이드 | 위와 같음(추정) | 위와 같음 | 위와 같음 | 위와 같음 | 같음 |
| 근접 센서(귀에 댐) · 안드로이드 | **추정: 화면이 꺼지지 않는다** — 근접 센서 화면 꺼짐은 전화 앱 · VoIP 앱이 쥐는 잠금이고 웹 페이지는 쥘 수 없다. 대신 **볼이 화면을 눌러** 버튼(종료 등)이 눌릴 위험이 있다 | — | — | — | 추정 — §4 B-5로 확인 |
| 다른 앱 전환 · 안드로이드 | 자동 꺼짐과 같은 계열(추정) | 같음 | 같음 | 같음 | 같음 |
| 탭 전환(같은 브라우저) | 크롬: 캡처 중인 탭은 계속 캡처될 수 있다(추정) | 같음 | 실시간 연결 탭은 타이머 제한 예외 [chrome57] | 계속 | 일부 문서 |
| 화면 잠금 · iOS 사파리 | **`muted`** — 스스로 풀리지 않는 경우가 있어 다시 열어야 한다 | **`interrupted`/suspended** — 복귀 후 `resume()`(때로 탭 필요) | 백그라운드 몇 초 뒤 끊길 수 있음(추정) | 멈춤 | WebKit 버그 리포트들 [wk204681][wk173268] · MDN AudioSession [mdn-as] · 포럼 [babylon] |
| iOS 홈 화면 앱(PWA) | 사파리와 같음 | 같음 | 같음 | 같음 | Wake Lock이 iOS 18.4 이전 PWA에서 동작 안 함 [wk254545] |

**결론**: 신고 증상(화면이 꺼지면 말이 전달 안 됨)의 가장 흔한 원인은 **화면 자동 꺼짐**으로 추정한다(통화는 몇 분 · 갤럭시 기본 꺼짐 30초 · 통화 중에는 화면을 만지지 않는다). 이것은 Screen Wake Lock으로 막을 수 있다. 전원 버튼 · 앱 전환은 막을 수 없으므로 "돌아왔을 때 복구"가 필요하다.

**종전 코드의 결함(코드로 확인)**: 소켓이 닫히면 `GeminiVoiceSession` onclose → `onEnded` → 통화 화면 `endCall("remote")`로 **통화가 끝났다**(`src/app/session/play/page.tsx` — `realtime.status === "ended"` 분기). 화면을 끈 것만으로 "상대가 끊은" 통화가 될 수 있었다. 전사는 메모리에만 있어 탭이 정리되면 사라졌다.
