실폰형 재설계 시안 목차 (UX v1.33 + 결정 2026-10-18)

통화 · 통화 중 문자 · 가짜 이체 페이지와 그 앞의 세션 전 화면을 실제 폰처럼 그린 정적 시안 모음이다. 링크 대신 파일 이름만 적었다 — 같은 폴더에서 파일을 직접 연다.

초록 칩 = 사용자 결정(2026-10-18) 반영 요소 파란 점선 = 시안 주석(실제 화면에는 없음) 프레임 375×812 · 라이트 · 상단 44px·하단 34px는 기기 안전 영역(가짜 상태바는 그리지 않음 — P-37 R-1)

이 폴더는 무엇인가

  • 정적 시안이며 앱 코드가 아니다. 앱(src/**)과 연결되지 않고, 각 HTML 파일은 혼자 열린다(인라인 CSS · 인라인 SVG 아이콘 · 외부 리소스 0).
  • 근거 스펙: docs/UX.md v1.33 패스 + 사용자 OQ 결정(2026-10-18) 반영본.
  • 기기 화면은 각 상태를 iOS형 / One UI형 두 프레임(375×812, 라이트)으로 나란히 그렸다. 세션 전 앱 화면은 앱 디자인 한 벌이다. 좁은 화면에서는 세로로 쌓인다.
  • 세션 중 화면에는 앱 표식을 그리지 않았다. 남는 앱 컨트롤은 "훈련 종료"(통화 셸에서는 가운데 빨간 종료 버튼) 하나다. 고지는 세션 전 화면에만 있다.
  • 아이콘은 이 시안용으로 직접 그린 단색 선 아이콘, 글꼴은 system-ui다(실제 OS 아이콘·글꼴·로고 파일 미사용).

파일 목록 (흐름 순서 · 같은 폴더의 파일을 직접 연다)

  • skin-select.html — 세션 전 화면 모양(기종) 선택: 자동 감지 iOS형 / 자동 감지 One UI형 / 감지 실패 = 기본 화면. 앱 화면 3장.
  • pre-call-notice.html — 세션 전 수신 직전 고지(짧은 고지 + "시작" + "훈련 종료"). 앱 화면 1장.
  • call-screens.html — 통화: ① 수신 ② 통화 중·스피커 꺼짐 ③ 통화 중·스피커 켜짐. 상태 3 × 프레임 2 = 6장.
  • in-call-sms.html — 통화 중 문자: Ⓐ 도착 배너 Ⓑ 문자함(인증번호) Ⓒ 문자함(안전계좌 2건). 상태 3 × 프레임 2 = 6장.
  • fake-transfer.html — 가짜 이체 페이지: Ⓐ 입력 중(가짜 주소 주소창 · 숫자 자판 메모) Ⓑ 완료. 상태 2 × 프레임 2 = 4장.

사용자 결정(2026-10-18)과 시안 반영

  • OQ-U58 벨소리·진동 — 기종별 기본 벨소리·진동을 가능하면 추가. 시안: 기종별 울림 연출 + 직전 고지 화면에 벨소리 예고. ⚠️ OS 원본 음원은 P-37 R-5와 충돌 — 유사 합성음 여부 확인 필요 · 진동 지원 범위는 architect 확인.
  • OQ-U59 스피커 — 실제로 스피커 모드 ↔ 통화 모드 전환. 시안: 실제 버튼 + 꺼짐/켜짐(밝게 반전) 두 상태. 실제 출력 전환을 먼저 시도하고, 불가 시 음량 크게/작게로 대체한다(가능 여부 architect 확인 필요).
  • OQ-U60 문자함 중 마이크 — 음소거하지 않고 통화 연결 유지. 시안: 통화 표시줄에 마이크 켜짐 아이콘 + 계속 흐르는 통화 시간, 음소거 표시 없음.
  • OQ-U61 스킨 전환 — 1순위 자동 감지, 2순위 선택 단계. 시안: skin-select.html.
  • OQ-U62 주소창 — 가짜 주소 입력. 시안: .invalid로 끝나는 가짜 도메인(jasanboho-transfer.invalid), 스킴 표기 0.
  • OQ-U63 모사 수준 — 역설계로 최대한 유사하게. 시안: 기종별 배경·버튼 모양·순서·말풍선 꼬리 등 배치 문법을 실폰에 가깝게 다듬음(아이콘·글꼴 파일 복제는 하지 않음). ⚠️ D-95(닮은 일반형)는 이 결정으로 대체 대상.
  • 결정 7 수신 화면 고지 — 수신 화면에 고지 없음, 그 전에 공지. 시안: pre-call-notice.html.
  • 미결 유지: OQ-U64(AC 추적 — planner) · OQ-U65(강제 다크 차단 선언 — 시안은 모두 라이트 선언).
