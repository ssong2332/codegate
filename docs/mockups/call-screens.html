통화 화면 시안 — 수신 · 통화 중(스피커 꺼짐/켜짐)

정적 시안(앱 코드 아님). 사용자 OQ 결정(2026-10-18) 반영본. 같은 상태를 iOS형 / One UI형 두 프레임으로 나란히 그렸다. 근거: docs/UX.md v1.33 — UX-014 노트 · P-10 · P-37 · D-86~D-88 · D-95, 결정 OQ-U58/U59/U61/U63.

초록 칩 = 사용자 결정(2026-10-18) 반영 요소 파란 점선 = 시안 주석(실제 화면에는 없음) 프레임 375×812 · 라이트 · 상단 44px·하단 34px는 기기 안전 영역(가짜 상태바는 그리지 않음 — P-37 R-1)

① 수신 화면 (phase = incoming)

훈련 관련 문구 0 — 고지는 직전 화면(pre-call-notice.html)으로 옮겼다. 번호 아래 줄은 비워 둔다(숨김 글 "전화가 오고 있습니다"). 기종별 배치: iOS형 = 왼쪽 거절 · 오른쪽 받기 / One UI형 = 왼쪽 받기 · 오른쪽 거절(실폰 배치를 따름 — 추정, 실기 대조 필요). 스와이프 없이 탭만(R-9).

② 통화 중 — 스피커 꺼짐(통화 모드)

번호 바로 아래 경과 시간. 2×3 단색 아이콘 그리드 + 하단 가운데 빨간 종료. 버튼 순서는 기종별 실폰 배치를 따랐다(추정 — iOS형: 음소거·키패드·스피커가 위 줄 / One UI형: 스피커·음소거·키패드가 종료 바로 위 줄).

③ 통화 중 — 스피커 켜짐(스피커 모드)

스피커를 누른 상태. 실제 폰처럼 버튼이 밝게 반전되고 aria-pressed="true". 다시 누르면 통화 모드(②)로 돌아간다.

시안 메모 — 결정 반영 중 임의로 정한 것(추정)

  • 버튼 위치: "역설계로 최대한 유사하게"(OQ-U63)에 따라 One UI형 수신 버튼을 좌우 반전(받기 왼쪽)하고, 통화 중 그리드 순서를 기종별로 바꿨다 — D-87의 칸 배치표(모든 스킨 공통)와 달라진다. 실기 대조 전 추정이다.
  • 소리: 사용자 결정은 "기종별 기본 벨소리". OS 원본 음원은 P-37 R-5상 쓸 수 없어(저작권·상표) 시안 캡션은 "기종별 유사 합성음"으로 적었다 — 원음 사용 여부는 별도 확인 필요.
  • 진동 표현: 번호 글자의 미세 흔들림은 시안 연출이다(실제 구현은 기기 진동 — 브라우저 지원 여부 미확인).
  • iOS형 배경은 흐린 사진 같은 방사형 그라데이션으로, One UI형은 위→아래 어두워지는 그라데이션으로 그렸다(실제 배경화면·연락처 사진 미사용).
  • iOS형 그리드는 backdrop-filter 흐림을 쓴다 — 지원하지 않는 브라우저에서는 반투명 단색으로 보인다.
