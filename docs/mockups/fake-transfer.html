가짜 이체 페이지 시안 — 입력 · 완료 (UX-023 v1.33)

정적 시안(앱 코드 아님). 기관 사칭 시나리오의 안전계좌 이체 페이지를 통화 중 문자에서 연 경우로 그렸다. 근거: docs/UX.md v1.33 — UX-023 노트 · P-20 증분 · P-37 · D-92~D-94 · OQ-U62.

노란 라벨 + 점선 = 결정 대기(OQ) 요소 — 스펙 권고안으로 그림 파란 점선 = 시안 주석(실제 화면에는 없음) 프레임 375×812 · 라이트 · 상단 44px·하단 34px는 기기 안전 영역(가짜 상태바는 그리지 않음 — P-37 R-1)

Ⓐ 가짜 이체 페이지 — 입력 상태 (통화 중 문자에서 연 경우)

① 통화 표시줄(탭 = 통화로 바로 복귀) → ② 브라우저 바(‹ 문자 · 주소창 · 훈련 종료) → ③ 기관 헤더 띠(남색 #1F3A5F + 일반형 방패) → ④ 본문 → ⑤ 입력 2칸 → ⑥ 제출 → ⑦ 닫기 → ⑧ 발급처. 주소창의 빨간 경고 아이콘·자물쇠 없음. 계좌번호 칸은 참가자가 문자를 보고 친 값(하이픈 포함)이 들어간 상태.

Ⓑ 가짜 이체 페이지 — 완료 상태

successHeadline + 복귀 버튼 1개. 통화 중 문자에서 열었으므로 버튼 문면 = "문자로 돌아가기". 입력값은 다시 보이지 않는다.

시안 메모 — 스펙이 정하지 않아 임의로 정한 것(추정)

  • 헤드라인 20px/700 · 안내 줄 15px · 완료 문구 18px/600 · 초점 테두리 2px #1F3A5F는 스펙에 크기·색이 없어 임의로 정했다.
  • 완료 화면의 복귀 버튼은 제출 버튼과 같은 #41525E 52px로 그렸다(현행은 앱 공용 버튼 — 낯선 사이트 느낌을 유지하려는 임의 선택).
  • 순서는 스펙 (1)대로 제출 → 닫기 → 발급처로 그렸다(현행 코드는 제출 → 발급처 → 닫기).
  • 브라우저 바: "‹ 문자" + 주소 필드 + "훈련 종료"를 한 줄 52px에 넣으면 375px에서 주소 표기가 말줄임된다.
  • 통화 표시줄 자막 문장은 예시다.
